# Wisedu · 学生画像分析系统

> 高校学生数据分析驾驶舱——一个老师打开就能用的可视化前端。

---

## 🎯 项目背景

高校积累了海量学生数据（成绩、考勤、一卡通、活动），但这些数据分散在不同系统里，老师和辅导员难以快速了解一个学生或一个群体的真实情况。

本系统把这些数据汇聚成**两张画像**：
- **个体画像**：一个学生的全面视图，从成绩到活动，从一卡通消费到成长轨迹
- **群组画像**：一个学院的宏观视图，让辅导员一眼看清整个年级的分布和趋势

## 👥 目标用户

- **辅导员 / 班主任**：快速掌握所带学生的综合情况，发现风险学生
- **学院教学秘书**：查看整体学情、综测分布、生源结构
- **学工部门**：宏观统计、决策支持

## 📊 核心数据

| 类别 | 字段 |
|------|------|
| 基本信息 | 学号、姓名、性别、学院、专业、年级、政治面貌 |
| 学业成绩 | GPA、班级排名、专业排名、课程成绩、挂科情况 |
| 综测数据 | 思想品德、学习能力、实践能力、创新能力、身体素质、文化素养 |
| 日常生活 | 一卡通消费、借阅图书、上网时长、请假次数 |
| 校园活动 | 活动次数、竞赛次数、社会实践、志愿服务 |
| 奖励处分 | 奖学金、荣誉称号、违纪处分 |
| 生源地 | 省份、民族、政治面貌 |

## 🛠 技术栈

| 层级 | 技术 |
|------|------|
| 框架 | Vue 3（CDN 全局构建） |
| 样式 | Tailwind CSS 3（CDN） |
| 图表 | ECharts 5 |
| 构建 | Vite 5 |
| 数据 | Mock 数据（纯前端，无后端依赖） |

> 注：曾尝试 Three.js 渲染 3D 人物，但由于 CDN 加载不稳定（ORB 拦截），最终用原生 `<img>` + AI 生成图片替代，稳定可靠。

## ✨ 核心功能

### 1. 个体画像
- 学生综合信息卡片（头像、姓名、学号、学院、标签）
- 综测雷达图（个人 vs 班级最高分 vs 班级均分）
- 校园活动圆环（文体/竞赛/社会实践/志愿服务占比）
- 成绩趋势折线（必修 vs 选修 3 学期对比）
- 日常生活数据（一卡通余额、借阅、上网、请假）
- 三好学生等荣誉徽章展示

### 2. 群组分析
- 学生人数概况（总数 / 在籍 / 男女比例半圆仪表）
- 政治面貌分布环形图
- 学生年龄结构横向柱状图
- 生源地中国地图（省份颜色深浅表示人数，含南海区域）
- 少数民族排行榜
- 综合素质发展（合格 vs 不合格 + 近 5 年综测趋势）
- 近 7 天请假情况折线图

### 3. 学生画像查询
- 多条件筛选（学号/姓名、学院、年级、性别、状态）
- 结果表格分页展示
- 一键跳转：点击任意学生行 → 自动进入该学生的个体画像页

### 4. 视图切换 + 图表生命周期管理
- 顶部导航三个系统级菜单（个体画像 / 群组分析 / 学生画像查询）
- Vue `watch` + `nextTick` 确保 ECharts 图表在 `v-if` 切换后正确重建
- 窗口 resize 自动响应式

## 🚀 快速启动

```bash
# 1. 安装依赖（如果还没装）
npm install

# 2. 启动开发服务器
npm run dev

# 3. 打开浏览器访问
# http://localhost:5173/
```

首次加载时，浏览器右上角控制台可能会提示 `cdn.tailwindcss.com should not be used in production`——这是 Tailwind CDN 的开发环境提示，不影响运行，生产环境替换为构建好的 CSS 即可。

## 💡 设计原则

1. **数据驱动视图**：Mock 数据集中在 `setup()` 里，改数据 → 页面自动联动（个体画像的雷达/圆环/折线均为 `computed`，随学生切换自动更新）
2. **图表安全**：ECharts 初始化前先检查 DOM 是否存在，地图加载失败自动降级为条形图，绝不因一个图表崩掉整页
3. **大屏适配**：`body { min-width: 1280px }` 确保三列布局不坍塌，小屏横向滚动
4. **开发环境**：Node.js 18+，Vite 5，`npm install && npm run dev` 即可启动
